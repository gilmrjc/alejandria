# Plantillas de Formato para Actions Proposal

## Plantilla de Plan de Trabajo

Usar al proponer acciones para resolver gaps:

```markdown
**PLAN DE TRABAJO**
- Fecha de creación: [YYYY-MM-DD]
- Versión del plan: [número incremental]
- Gaps a resolver: [cantidad]
- Prioridad de ejecución: [orden de prioridad]

**Calificación del documento**:
- Calificación actual: X/10
- Calificación esperada después del plan: Y/10
- Mejora esperada: +Z puntos

**Desglose de mejoras por criterio**:
- Estructura: X/10 → Y/10 (+Z puntos)
- Contenido: X/10 → Y/10 (+Z puntos)
- Densidad: X/10 → Y/10 (+Z puntos)
- Tamaño: X/10 → Y/10 (+Z puntos)
- Perspectiva Dual: X/10 → Y/10 (+Z puntos)
```

## Plantilla de Ediciones a Archivos Existentes

Usar al proponer ediciones a archivos existentes:

```markdown
**EDICIONES A ARCHIVOS EXISTENTES PROPUESTAS**

### Archivo: [ruta del archivo]
- **Gap relacionado**: [Título del gap]
- **Acción propuesta**: [Descripción de la edición a realizar]
- **Justificación**: [Por qué este archivo es el lugar apropiado]
- **Referencias necesarias**: [fuentes a consultar]
- **Resultado esperado**: [descripción del resultado]
```

## Plantilla de Integración de Respuestas

Usar al integrar respuestas encontradas al documento:

```markdown
**RESPUESTA INTEGRADA**
- Gap original: [Título del gap]
- Fecha de respuesta: [YYYY-MM-DD]
- Respuesta: [Contenido de la respuesta]
- Referencias: [Fuentes consultadas]
- Estado actual: [RESPONDIDO]
```

## Plantilla de Sugerencia de Consolidación

Usar al sugerir organización de hallazgos:

```markdown
**SUGERENCIA DE CONSOLIDACIÓN**
- Tipo de documento sugerido: [ADR/PRD/Especificación Técnica/etc.]
- Razón: [Justificación de por qué se necesita consolidación]
- Gaps a incluir: [Lista de gaps relacionados]
- Beneficio esperado: [Mejora en organización y accesibilidad]
```

## Plantilla de Validación de Plan Vigente

Usar al validar si un plan de trabajo existente sigue siendo vigente:

```markdown
**VALIDACIÓN DE PLAN VIGENTE**
- Fecha de validación: [YYYY-MM-DD]
- Plan original versión: [número]
- Gaps pendientes en plan: [cantidad]
- Gaps nuevos identificados: [cantidad]
- Gaps obsoletos: [cantidad]
- Requiere actualización: [SÍ/NO]
- Motivo de actualización: [Descripción si aplica]
```
