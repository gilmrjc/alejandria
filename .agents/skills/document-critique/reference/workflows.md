# Flujos de Trabajo del Proceso

## Resumen

El proceso sigue un enfoque sistemático adaptable a cualquier tipo de documento: (1) detección de análisis previo, (2) preparación y clasificación del tipo de documento, (3) evaluación de gaps previos si aplica, (4) validación de respuestas y consistencia por rol, (5) investigación de referencias por rol, (6) identificación de contexto faltante por rol, (7) evaluación de calidad y decisión de adición de gaps, y (8) revisión integrativa final. El proceso se adapta dinámicamente según el tipo de documento identificado (estratégico, de producto, técnico, de usuario, de gestión, etc.).

## Pasos del Proceso

Para instrucciones detalladas paso a paso, consultar los siguientes archivos:

- **[Paso 0: Detección de Análisis Previo](./workflows/00-detection.md)** - Determinar si existe un análisis previo y validar su vigencia
- **[Paso 1: Preparación y Clasificación](./workflows/01-classification.md)** - Determinar tipo de documento, roles funcionales y perspectivas
- **[Paso 2: Evaluación de Gaps Previos](./workflows/02-gaps-validation.md)** - Validar estado de gaps existentes y actualizar según corresponda
- **[Paso 3: Validación de Respuestas y Consistencia](./workflows/03-validation.md)** - Para cada rol funcional, validar respuestas existentes y consistencia cruzada
- **[Paso 4: Investigación de Referencias](./workflows/04-investigation.md)** - Para cada rol funcional, revisar archivos de referencia
- **[Paso 5: Identificación de Contexto Faltante](./workflows/05-identification.md)** - Para cada rol funcional, identificar contexto faltante con preguntas clave
- **[Paso 6: Evaluación de Calidad](./workflows/06-quality-evaluation.md)** - Calificar documento y decidir adición de gaps
- **[Paso 7: Revisión Final](./workflows/07-final-review.md)** - Verificar cobertura multi-rol, consistencia y criterios de terminación
