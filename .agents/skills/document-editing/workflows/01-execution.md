# Paso 1: Ejecución de Acciones Propuestas

## Objetivo

Aplicar las acciones propuestas en el plan de trabajo en el orden establecido por prioridad y tipo de acción.

## Orden de Ejecución

Ejecutar las acciones en el siguiente orden jerárquico:

### Por Prioridad

1. **Prioridad 1: Crítica** - Acciones que bloquean desarrollo o toma de decisiones
2. **Prioridad 2: Alta** - Acciones importantes pero no bloqueantes
3. **Prioridad 3: Media** - Acciones deseables que pueden postponerse

### Por Tipo de Acción (dentro de cada prioridad)

1. **Ediciones del archivo actual** (primero)
2. **Ediciones a archivos existentes** (segundo)
3. **Creación de nuevos archivos** (tercero, último recurso)

## Proceso para Ediciones del Archivo Actual

Para cada acción de tipo "Edición del archivo actual":

1. **Leer la descripción de la acción**: Entender qué cambio se debe realizar
2. **Localizar la sección relevante**: Encontrar la parte del documento donde se debe aplicar el cambio
3. **Consultar referencias**: Revisar las fuentes necesarias para ejecutar la acción
4. **Aplicar la edición**: Realizar el cambio específico descrito en la acción
5. **Verificar el resultado**: Confirmar que el cambio se aplicó correctamente
6. **Documentar la ejecución**: Registrar que la acción fue completada

## Proceso para Ediciones a Archivos Existentes

Para cada acción de tipo "Edición a archivo existente":

1. **Leer la descripción de la acción**: Entender qué cambio se debe realizar
2. **Identificar el archivo objetivo**: Localizar el archivo existente especificado en la acción
3. **Validar existencia del archivo**: Confirmar que el archivo existe y es accesible
4. **Consultar referencias**: Revisar las fuentes necesarias para ejecutar la acción
5. **Aplicar la edición**: Realizar el cambio específico descrito en la acción
6. **Verificar el resultado**: Confirmar que el cambio se aplicó correctamente
7. **Documentar la ejecución**: Registrar que la acción fue completada

## Proceso para Creación de Nuevos Archivos

Para cada acción de tipo "Creación de nuevo archivo":

1. **Leer la descripción de la acción**: Entender qué archivo se debe crear
2. **Determinar la ubicación**: Identificar la ruta donde se debe crear el archivo
3. **Consultar referencias**: Revisar las fuentes necesarias para crear el contenido
4. **Crear el archivo**: Generar el archivo con el contenido especificado
5. **Verificar el resultado**: Confirmar que el archivo se creó correctamente
6. **Documentar la ejecución**: Registrar que la acción fue completada

**Importante**: Solo crear información que exista en las respuestas de gaps. Si el archivo requiere información adicional según el plan, marcar esa sección o campo como pendiente de información. No derivar información a partir de inferencias o supuestos.

## Principios de Ejecución

- **Fidelidad al plan**: Implementar exactamente las acciones propuestas, sin añadir ni quitar
- **Orden estricto**: Seguir el orden de prioridad y tipo de acción establecido
- **Verificación continua**: Verificar cada cambio antes de continuar con el siguiente
- **Documentación completa**: Registrar cada acción ejecutada con su resultado
- **Sin invención**: NO agregar información no existente ni inventar razonamientos

## Criterios de Terminación

Este paso termina cuando:

- Se han ejecutado todas las acciones de prioridad Crítica
- Se han ejecutado todas las acciones de prioridad Alta
- Se han ejecutado todas las acciones de prioridad Media
- Todas las ediciones han sido verificadas
- Todas las ejecuciones han sido documentadas

## Salida

- Lista de acciones ejecutadas
- Archivos modificados o creados
- Confirmación de que todas las acciones del plan fueron ejecutadas
