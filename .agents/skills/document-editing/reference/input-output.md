# Expectativas de Entrada/Salida

## Entrada

- Un documento de cualquier tipo (recién creado, con gaps, o con evaluación previa)
- Acceso al contexto del proyecto si es necesario para entender el documento

## Salida

### Si calificación ≥ 9

1. **Resumen de revisión**: Breve descripción de la evaluación realizada
2. **Calificación**: Puntaje numérico con justificación
3. **Confirmación**: Documento listo para uso
4. **Propuesta de documentos siguientes**: Documentos lógicos como siguientes pasos para extender la documentación (siempre incluido, independiente de calificación)

### Si calificación < 9

1. **Resumen de revisión**: Breve descripción de la evaluación realizada
2. **Calificación**: Puntaje numérico con justificación
3. **Propuesta de estructura** (si aplica): Nueva estructura alineada con objetivo
4. **Mejoras de contenido por sección**: Detalle de mejoras necesarias sección por sección (con énfasis en balance texto/listas)
5. **Propuesta de división** (si aplica por densidad o tamaño): Estructura de archivos atómicos
6. **Re-evaluación de análisis previos** (si aplica): Estado de gaps y sugerencias existentes
7. **Justificación de tamaño** (si aplica por exceso de 300 líneas): Razón para mantener documento unificado o propuesta de división
8. **Propuesta de documentos siguientes**: Documentos lógicos como siguientes pasos para extender la documentación (siempre incluido, independiente de calificación)
